# Changelog

## 0.2.0.dev0

Local development build, September 15, 2026. macOS qualification remains open.

- Directory rules can select scoped font/padding/margin profiles or allowlisted whole-process kitty config overlays.
- Focused-OS arbitration, base-derived reloads, scoped suspension, live ownership checks, and restoration retries.
- PNG, JPEG, static GIF, and animated GIF backgrounds with bounded conversion and playback.
- Native profile qualification on kitty 0.38.1/0.48.2, X11/Wayland, and Bash/Zsh/Fish.
